# Алиса как канал JARVIS (D18.1–D18.3)

Чтобы говорить «Алиса, спроси Джарвиса какая погода» на Станции и получать
ответ от Jarvis, нужны три вещи:

1. **Webhook** в JARVIS (уже готов: `POST /api/alice/webhook`).
2. **Публичный туннель** до localhost:8000.
3. **Регистрация Навыка** на dialogs.yandex.ru (бесплатно, привязан только к
   твоему Yandex-аккаунту, в маркет не публикуем).

---

## Выбор tunnel

Проверены три варианта:

| Tool | Работает в РФ | Стабильность | Setup |
|---|---|---|---|
| **ngrok** | ❌ блочит русские IP (`ERR_NGROK_9040`) | — | — |
| **Cloudflare Tunnel (quick)** | ⚠ через раз (error 1033) | низкая | без аккаунта |
| **localtunnel** | ✅ работает | средняя | один `npm install` |

Используем **localtunnel**. Альтернатива на будущее — Cloudflare Tunnel с
зарегистрированным аккаунтом и своим доменом (стабильнее, статичный URL).

## Шаг 1. Установка localtunnel (один раз)

Node.js у тебя уже стоит. Установка:

```powershell
npm install -g localtunnel
```

Проверка: `lt --help` должен показать справку.

## Шаг 2. Запуск туннеля

```powershell
cd "C:\Users\Staho\Documents\Claude\Projects\ДЖАРВИС (2)\jarvis"
.\scripts\start_alice_tunnel.bat
```

В окне появится:

```
your url is: https://jarvis-boss.loca.lt
```

Полный webhook URL:

```
https://jarvis-boss.loca.lt/api/alice/webhook
```

**Не закрывай это окно**, пока пользуешься Навыком — туннель работает только
пока процесс жив.

> **Один нюанс localtunnel:** при первом заходе с браузера показывает
> tunnel-password страницу. POST-запросы от Алисы это не зацепит (она шлёт
> JSON, не открывает HTML), так что для нашего use case не критично. Если
> Yandex таки начнёт на это спотыкаться — переключимся на Cloudflare Tunnel
> с аккаунтом.

## Шаг 3. Регистрация Навыка на dialogs.yandex.ru

1. Открыть https://dialogs.yandex.ru/developer/
2. **Создать диалог** → тип **Навык в Алисе**
3. Заполнить поля:
   - **Название:** `Джарвис` (или любое — это то, как Алиса будет распознавать
     при «спроси у …»)
   - **Активационное имя:** `джарвис`
   - **Аватар:** любой
   - **Голос:** `Алиса` (стандартный) — для TTS-ответов
4. Раздел **Backend** → **Webhook URL**:
   `https://jarvis-boss.loca.lt/api/alice/webhook`
5. **Брандмауэр:** «Без проверки» (или см. ниже про `alice_skill_id`).
6. **Приватный навык:** в настройках поставить **Приватный** — будет доступен
   только тебе, без публикации в маркете.
7. **Опубликовать на тестирование** — раздел *Тестирование* справа.
8. На Станции / в Алисе:
   ```
   Алиса, запусти навык Джарвис
   Алиса, спроси у Джарвиса какие задачи
   ```

## Шаг 4. (Опционально) Защита по skill_id

После создания навыка в URL `dialogs.yandex.ru/developer/skills/XXXX/...` есть
`XXXX` — это `skill_id`. Добавь в `.env`:

```env
ALICE_SKILL_ID=XXXX
```

Webhook будет принимать только запросы с этим `skill_id` и игнорировать
левые запросы (если кто-то найдёт `jarvis-boss.loca.lt` и попробует туда
POST'ить).

## Что Алиса умеет через JARVIS

Через канал `alice` работают все **локальные** skills:

| Группа | Примеры команд |
|---|---|
| Время | «который час», «какое сегодня число» |
| Задачи | «добавь задачу X», «покажи задачи», «выполнил #2» |
| Напоминания | «напомни через 30 минут позвонить», «покажи напоминания» |
| Память | «запомни Y», «что я говорил про Z» |
| Заметки | «запиши: X» |
| Калькулятор | «посчитай 2 плюс 2» |
| Конвертация | «переведи 100 долларов в рубли» |
| Погода | «погода в Москве» (если есть кэш — мгновенно) |
| Поиск | «погугли рецепт борща» (может срезаться по таймауту) |

**Ограничение:** Алиса даёт навыку **≤2 секунды** на ответ. Локальные skills
укладываются всегда. Запросы к Claude/Yandex GPT иногда не успевают, и Алиса
скажет «Босс, сейчас думаю — переспроси через пару секунд». Это by design —
Алиса просто не умеет ждать дольше.

## Phase 2 (D18.4) — JARVIS → устройства

Управление умными устройствами через JARVIS («Джарвис, включи свет») — это
D18.4, не реализовано. Сейчас Алиса умеет управлять устройствами сама — JARVIS
в этом не участвует. Phase 2 решает обратное: чтобы Jarvis _сам_ мог
скомандовать устройствам через Yandex.

## Troubleshooting

- **«Навык не отвечает»** — проверь:
  1. `run_web_hud.py` запущен (порт 8000 listening).
  2. `start_alice_tunnel.bat` запущен (node-процесс жив).
  3. `curl.exe https://jarvis-boss.loca.lt/api/alice/webhook` отвечает.
- **Алиса просит зайти в навык каждый раз** — это нормально в режиме
  «тестирование». После публикации «приватного навыка» можно говорить
  «Алиса, спроси у Джарвиса …» без явного запуска.
- **Логи webhook**: смотри в окне `run_web_hud.py` — там видно
  `bus_event channel=alice kind=user_input` для каждого запроса.
- **localtunnel периодически роняет соединение** — просто перезапусти
  `start_alice_tunnel.bat`. URL не меняется (subdomain зафиксирован).
