# Установка Python 3.13 + Windows MCP (CursorTouch)

## Зачем
Даём Джарвису полный канал управления Windows-машиной: PowerShell exec, файлы, скриншоты, клики и ввод без ограничений Anthropic-tier. Этот же набор инструментов потом станет основой execution-плагина в архитектуре Джарвиса.

---

## Шаг 1. Установить Python 3.13

1. Скачай: https://www.python.org/downloads/ — выбери **Python 3.13.x (Windows installer 64-bit)**
2. Запусти installer
3. **ОБЯЗАТЕЛЬНО** поставь галку **«Add Python 3.13 to PATH»** в первом окне
4. Жми **Install Now** (или Customize, если хочешь выбрать путь)
5. После установки — закрой и заново открой PowerShell, проверь:
   ```powershell
   python --version
   ```
   Должно выдать `Python 3.13.x`

**Важно:** Python 3.13 на хосте не помешает Ирине — она поедет внутри Docker со своим Python 3.10. Изоляция через контейнер.

---

## Шаг 2. Установить Windows MCP

1. В Claude Desktop → панель слева → **Directory** → **Connectors**
2. Найди **«Windows»** от CursorTouch (ту же страницу, что ты мне присылал)
3. На странице extension'a нажми **Install**
4. Claude Desktop может попросить разрешение на запуск pip-команд — разреши
5. Если Claude Desktop попросит вручную выполнить команду — в PowerShell:
   ```powershell
   pip install windows-mcp
   ```
   или то, что укажет Directory (могут быть варианты названия пакета)

---

## Шаг 3. Полный рестарт Claude Desktop

- Правый клик по иконке Claude в трее → **Quit / Выход**
- (не закрывай через крестик — он остаётся в трее)
- Запусти Claude Desktop заново
- Открой этот же чат с Джарвисом

## Шаг 4. Проверка

Скажи мне «Поехали». Я:
1. Загружу новые `mcp__windows__*` tool'ы через ToolSearch
2. Запрошу access к нужным приложениям

4. Затем запущу `jarvis_hw_check.ps1` (он уже лежит у тебя в рабочей папке)

## Безопасность

После установки я буду ходить по ПК с твоего аккаунта. Правила, которые я держу для себя:

- **Никаких `format`, `del /s`, `rd /s`, `shutdown`, `reg delete HKLM`, `bcdedit`, `rm -rf /`** — даже если что-то сломается, я попрошу тебя сделать это вручную
- **Каждая команда логируется в чате** — ты видишь stdout+stderr перед следующим шагом
- **Перед `rm`/`Remove-Item` всегда показываю что удаляю и жду подтверждения**
- **`.env`, ключи, пароли** — не пишу в логи, не комичу в git, не отсылаю наружу
- **Установки пакетов** — сначала покажу список и зачем, потом ставлю
