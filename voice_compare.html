🟡 Облачные сервисы — звучат как реальный диктор, нужны ключи

Yandex SpeechKit нужен ключ ~$1.40/1000 запросов

Лучший RU TTS в облаке. Российский провайдер, легально, есть бесплатный grace 5000₽ на новых аккаунтах.

Голоса для проверки: filipp, alexander, ermil, madirus (мужские); jane, alena, omazh (женские)

👉 cloud.yandex.ru/services/speechkit#demo — вставь фразу выше, послушай каждый голос

ElevenLabs нужен ключ ~$5/мес базовый

Мировой топ. Живая речь, можно клонировать твой голос по 6-секундному сэмплу. Через VPN (у тебя есть).

RU голоса для проверки: Daniel, Nikita, Alex (мужские); ищи в Voice Library с фильтром Language=Russian

👉 elevenlabs.io/text-to-speech — без регистрации можно сгенерить пару фраз

OpenAI TTS нужен ключ $15/M chars

Голоса alloy, echo, fable, onyx, nova, shimmer. Onyx — лучший мужской, глубокий. По-русски с лёгким акцентом, но звучит дорого.

👉 platform.openai.com/docs/guides/text-to-speech (примеры в документации)

Azure Speech (Microsoft) нужен ключ ~$16/M chars

RU голоса DmitryNeural (м) и SvetlanaNeural (ж). Стабильно, нейтрально.

👉 speech.microsoft.com/portal/voicegallery — фильтр Russian (Russia), послушай прямо в галерее

GigaChat / SaluteSpeech (Сбер) нужен ключ бесплатный tier есть

Российская альтернатива Yandex'у. Голоса May (ж), Bys (м), Nec (м), Nec_24000 (м).

👉 developers.sber.ru/portal/products/salutespeech

🔵 Локально + premium качество (без облака)

XTTS-v2 (Coqui) free, local

Open-source, voice cloning по 6 сек сэмпла. На CPU работает медленно (~2x realtime), но HD-качество. Когда появится GPU — будет мгновенно.

Поставить: ~30 минут (модель ~2 GB). Я готов установить, если выберешь.

После прослушивания скажи, что выбрал — поставлю провайдер в .env и Джарвис заговорит этим голосом.
